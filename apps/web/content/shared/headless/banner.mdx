## What it does

`Banner.*` gives you the banner's behaviour in pieces: when it shows, what each button does, the translated text. You supply the elements and the classes. The result behaves exactly like [`CookieBanner`](/docs/components/cookie-banner).

Use it only when `CookieBanner` cannot produce the markup your design needs. For colours, spacing or fonts, restyle `CookieBanner` instead; it is much less work.

## Build a banner

<Framework when="nextjs react vue svelte">

Render this in place of `<CookieBanner />`. `Banner.Root` decides when the banner shows and hides, so keep it as the outer element.

</Framework>

<Framework when="nuxt">

Write the banner as a component, then render it in place of `<CookieBanner />` inside `<CookieYesRoot>`. `Banner.Root` decides when the banner shows and hides, so keep it as the outer element.

</Framework>

<Framework when="sveltekit">

Write the banner as a component, then render it in place of `<CookieBanner />` in the `ui` snippet of `<CookieYesRoot>`. `Banner.Root` decides when the banner shows and hides, so keep it as the outer element.

</Framework>

<Framework when="nextjs react">

```tsx title="app/consent-banner.tsx"
"use client";

import { Banner, useRegulation } from "@cookieyes/react";

export function ConsentBanner() {
  const isCCPA = useRegulation() === "CCPA";

  return (
    <Banner.Root className="banner">
      <Banner.Title className="banner-title" />
      <Banner.Description className="banner-text" />
      <Banner.Actions className="banner-actions">
        {isCCPA ? (
          <Banner.DoNotSell className="btn" />
        ) : (
          <>
            <Banner.AcceptAll className="btn btn-primary" />
            <Banner.RejectAll className="btn" />
          </>
        )}
        <Banner.OpenPreferences className="btn btn-link" />
      </Banner.Actions>
    </Banner.Root>
  );
}
```

</Framework>

```vue title="app/components/ConsentBanner.vue" group="banner"
import { Banner } from "#imports";

        <Banner.AcceptAll class="btn btn-primary" />
        <Banner.RejectAll class="btn" />
      </template>
      <Banner.OpenPreferences class="btn btn-link" />
    </Banner.Actions>
  </Banner.Root>
</template>
```

Nuxt imports `Banner` for you in script, but a template only sees `Banner.Root` and the other pieces when `Banner` is a binding of the component, so import it from `#imports`, as above. `useRegulation()` needs no import.

The slot of `<CookieYesRoot>` replaces everything it renders by default, so list the other components you still want:

```vue title="app/app.vue" group="banner"
<template>
  <CookieYesRoot>
    <ConsentBanner />
    <CookiePreferences />
    <CookieOptOut />
    <RecallButton />
  </CookieYesRoot>
  <NuxtPage />
</template>
```

Inside the slot your banner gets the consent the module read from the request, so a returning visitor gets no banner in the server HTML.

</Framework>

<Framework when="svelte">

```svelte title="src/lib/ConsentBanner.svelte"
<script lang="ts">
  import { Banner, useRegulation } from "@cookieyes/svelte";

  const regulation = useRegulation();
</script>

<Banner.Root class="banner">
  <Banner.Title class="banner-title" />
  <Banner.Description class="banner-text" />
  <Banner.Actions class="banner-actions">
    {#if regulation.current === "CCPA"}
      <Banner.DoNotSell class="btn" />
    {:else}
      <Banner.AcceptAll class="btn btn-primary" />
      <Banner.RejectAll class="btn" />
    {/if}
    <Banner.OpenPreferences class="btn btn-link" />
  </Banner.Actions>
</Banner.Root>
```

Every piece is also exported on its own, as `BannerRoot`, `BannerTitle`, `BannerAcceptAll` and so on. Both name the same component; use whichever reads better.

`Banner.Root` moves itself into `#cookieyes-portal-root`, a child of `<body>`, once mounted, so it sits above your page content wherever you render it.

</Framework>

The `ui` snippet of `<CookieYesRoot>` replaces everything it renders by default, so list the other components you still want:

```svelte title="src/routes/+layout.svelte"
<script lang="ts">
  import {
    CookieOptOut,
    CookiePreferences,
    CookieYesRoot,
    RecallButton,
  } from "@cookieyes/sveltekit";
  import ConsentBanner from "../lib/ConsentBanner.svelte";
  import { config } from "../lib/cookieyes";

  let { data, children } = $props();
</script>

<CookieYesRoot {config} state={data.consent}>
  {#snippet ui()}
    <ConsentBanner />
    <CookiePreferences />
    <CookieOptOut />
    <RecallButton />
  {/snippet}
  {@render children()}
</CookieYesRoot>
```

Inside `<CookieYesRoot>` your banner gets the consent the handle read from the request, so a returning visitor gets no banner in the server HTML. `Banner.Root` moves itself into `#cookieyes-portal-root`, a child of `<body>`, once mounted.

</Framework>

## The pieces

| Piece | Renders | What it does |
| --- | --- | --- |
| `Banner.Root` | `<div>` | Shows the banner until the visitor chooses, then hides it. Keep it as the wrapper |
| `Banner.Title` | `<h2>` | The banner heading |
| `Banner.Description` | `<p>` | The banner text; switches to the CCPA wording automatically |
| `Banner.Actions` | `<div>` | A plain container for the buttons |
| `Banner.AcceptAll` | `<button>` | Accepts every category |
| `Banner.RejectAll` | `<button>` | Rejects every optional category |
| `Banner.OpenPreferences` | `<button>` | Opens the preferences dialog, so render `CookiePreferences` too |
| `Banner.DoNotSell` | `<button>` | Opens the CCPA opt-out dialog, so render `CookieOptOut` too |
| `Banner.Close` | `<button>` | Hides the banner for this page view. Saves nothing; the banner returns on the next page load |
| `Banner.Branding` | `<a>` | The "Powered by" link |

<Framework when="nextjs react">

Every piece takes `className`, `style` and the other props of the element it renders. The part names for CSS are the same as on [`CookieBanner`](/docs/components/cookie-banner#restyle-it).

</Framework>

## Use your own button component

<Framework when="nextjs react">

Add `asChild` to a button piece and pass one element. The piece puts its behaviour on your element instead of rendering its own `<button>`:

```tsx check="false"
<Banner.AcceptAll asChild>
  <MyButton variant="primary">Accept all</MyButton>
</Banner.AcceptAll>
```

</Framework>

<Framework when="vue nuxt">

Add `as-child` to a button piece and pass one element. The piece puts its behaviour on your element instead of rendering its own `<button>`. It throws if the slot holds anything other than exactly one element:

```vue check="false"
<Banner.AcceptAll as-child>
  <MyButton variant="primary">Accept all</MyButton>
</Banner.AcceptAll>
```

</Framework>

<Framework when="svelte">

Give a button piece a `child` snippet. It receives `{ props }`: the attributes and click handler of the piece. Spread them onto your own element, and the piece renders that instead of its own `<button>`:

```svelte title="src/lib/AcceptLink.svelte"
<script lang="ts">
  import { Banner } from "@cookieyes/svelte";
</script>

<Banner.AcceptAll>
  {#snippet child({ props })}
    <a {...props} href="#accepted">Accept all</a>
  {/snippet}
</Banner.AcceptAll>
```

Your own click handler, passed as `onclick`, runs first; call `event.preventDefault()` in it to stop the consent action.

</Framework>

<Framework when="sveltekit">

Give a button piece a `child` snippet. It receives `{ props }`: the attributes and click handler of the piece. Spread them onto your own element, and the piece renders that instead of its own `<button>`:

## Common mistakes

**The banner shows for visitors who already chose.**
`Banner.Root` is missing, or something else wraps the pieces. It must be the outer element.

<Framework when="nextjs react">

**A button renders inside another button.**
Your component already renders a `<button>`. Add `asChild`.

</Framework>

<Framework when="vue nuxt">

**A button renders inside another button.**
Your component already renders a `<button>`. Add `as-child`.

</Framework>

<Framework when="svelte sveltekit">

**A button renders inside another button.**
You put your button component between the piece's tags. Use a `child` snippet and spread `props` onto it.

</Framework>

**Customise does nothing.**
`CookiePreferences` is not rendered. `Banner.OpenPreferences` only opens it.

<Framework when="nuxt">

**Nothing renders, and the console says it failed to resolve `Banner.Root`.**
`Banner` is not imported in the component. Add `import { Banner } from "#imports";` to its `<script setup>`.

</Framework>

**The banner sits behind a sticky header.**
Raise the `z-index` on your `Banner.Root` class.
