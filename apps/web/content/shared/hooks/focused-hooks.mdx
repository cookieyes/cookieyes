## What they are

<Framework when="nextjs react">

[`useConsent()`](/docs/hooks/use-consent) gives you everything and re-renders on every change. The hooks on this page each answer one question and re-render only when that answer changes. None of them throws: before the runtime is ready they return a safe default.

</Framework>

<Framework when="vue">

[`useConsent()`](/docs/hooks/use-consent) gives you everything and updates on every change. The composables on this page each answer one question and change only when that answer changes. They return computed refs, so read `.value` in script and use them directly in templates; the Returns column is the type of that value. `useLanguage()` and `useReloadNotice()` return an object whose fields are refs, plus functions. Every one of them throws if `app.use(CookieYes, config)` has not run, and must be called inside `setup()`.

</Framework>

<Framework when="nuxt">

[`useConsent()`](/docs/hooks/use-consent) gives you everything and updates on every change. The composables on this page each answer one question and change only when that answer changes. They return computed refs, so read `.value` in script and use them directly in templates; the Returns column is the type of that value. `useLanguage()` and `useReloadNotice()` return an object whose fields are refs, plus functions. Nuxt imports every one of them for you; call them inside `setup()` or `<script setup>`.

</Framework>

<Framework when="svelte">

[`useConsent()`](/docs/hooks/use-consent) gives you everything and updates on every change. The hooks on this page each answer one question. A hook that answers with one value (`useConsentCategory`, `useRegulation`, `useBannerVisibility`, `usePreferencesOpen`, `useOptOutOpen`) returns it as `{ current }`, because a function cannot return a reactive value; the Returns column is the type of `current`. The others return an object whose fields stay reactive when read in a template or a `$derived`; destructuring reads them once. Every one of them throws if no `<CookieYesProvider>` is above the component, and must be called while the component initialises.

</Framework>

<Framework when="sveltekit">

[`useConsent()`](/docs/hooks/use-consent) gives you everything and updates on every change. The hooks on this page each answer one question. A hook that answers with one value (`useConsentCategory`, `useRegulation`, `useBannerVisibility`, `usePreferencesOpen`, `useOptOutOpen`) returns it as `{ current }`, because a function cannot return a reactive value; the Returns column is the type of `current`. The others return an object whose fields stay reactive when read in a template or a `$derived`; destructuring reads them once. Every one of them throws if the component is not rendered inside `<CookieYesRoot>`, and must be called while the component initialises.

</Framework>

| You want to know | Hook | Returns |
| --- | --- | --- |
| Is one category granted? | `useConsentCategory("analytics")` | `boolean`, the saved value |
| Which privacy law applies? | `useRegulation()` | `"GDPR"` or `"CCPA"` |
| Why that law? | `useRegion()` | `{ region, regulation, source, confidence }` |
| Which categories are configured? | `useCategories()` | `{ list, ids, requiredIds, isDefault }` |
| Is the banner on screen? | `useBannerVisibility()` | `boolean` |
| Is a dialog open? | `usePreferencesOpen()`, `useOptOutOpen()` | `boolean` |
| What is the text in the active language? | `useTranslations()` | the translation map |
| Which language is active, and how do I switch it? | `useLanguage()` | `{ language, direction, languages, setLanguage }` |
| Does a change need a page reload? | `useReloadNotice()` | `{ required, reasons, dismiss }` |

## Show something only with consent

<Framework when="nextjs react">

```tsx title="app/analytics-widget.tsx"
"use client";

import { useConsentCategory } from "@cookieyes/react";

export function AnalyticsWidget() {
  const allowed = useConsentCategory("analytics");
  if (!allowed) return <p>Enable analytics cookies to see your dashboard.</p>;
  return <iframe title="Dashboard" src="https://analytics.example.com/embed" />;
}
```

</Framework>

<Framework when="vue">

```vue title="src/components/AnalyticsWidget.vue"
<script setup lang="ts">
import { useConsentCategory } from "@cookieyes/vue";

const allowed = useConsentCategory("analytics");
</script>

<template>
  <iframe v-if="allowed" title="Dashboard" src="https://analytics.example.com/embed" />
  <p v-else>Enable analytics cookies to see your dashboard.</p>
</template>
```

The category can also be a ref or a getter, such as `useConsentCategory(() => props.category)`.

</Framework>

```vue title="app/components/AnalyticsWidget.vue"

```

The category can also be a ref or a getter, such as `useConsentCategory(() => props.category)`.

</Framework>

<Framework when="svelte">

```svelte title="src/lib/AnalyticsWidget.svelte"
<script lang="ts">
  import { useConsentCategory } from "@cookieyes/svelte";

  const allowed = useConsentCategory("analytics");
</script>

{#if allowed.current}
  <iframe title="Dashboard" src="https://analytics.example.com/embed"></iframe>
{:else}
  <p>Enable analytics cookies to see your dashboard.</p>
{/if}
```

The category can also be a getter, such as `useConsentCategory(() => category)` for a `category` prop, so it stays reactive.

</Framework>

<Framework when="sveltekit">

```svelte title="src/lib/AnalyticsWidget.svelte"

```

The category can also be a getter, such as `useConsentCategory(() => category)` for a `category` prop, so it stays reactive.

</Framework>

`useConsentCategory` reads the **saved** value, so a switch flipped in the dialog but not saved changes nothing here. For an `<iframe>` with a ready-made placeholder, [`GatedFrame`](/docs/components/gated-frame) does this for you.

## Which law applies, and why

`useRegulation()` returns the law in effect: `"GDPR"` or `"CCPA"`.

`useRegion()` tells you how that was decided, which is the tool when a visitor sees an unexpected banner. `source` is `"manual"` when you set `regulation` yourself, `"detected"` when `region.detect` matched your `region.map`, and `"strictest"` when detection found nothing and `region.strictest` applied. `confidence` is `"low"` when the region was guessed.

## Build your own category list

<Framework when="nextjs react">

`useCategories()` returns your configured categories in order (`list`), their ids, the ids that are always on (`requiredIds`), and `isDefault`, which is `true` when the built-in five are in effect. Render from `list` rather than writing the five names by hand, so custom categories appear automatically. The list is fixed when the runtime starts, so this hook never re-renders.

</Framework>

<Framework when="vue nuxt">

Render from `list` rather than writing the five names by hand, so custom categories appear automatically. The list is fixed when the runtime starts, so it never changes.

</Framework>

<Framework when="svelte sveltekit">

Render from `list` rather than writing the five names by hand, so custom categories appear automatically. The list is fixed when the runtime starts, so it is a plain object that never changes.

</Framework>

## The banner and the dialogs

`useBannerVisibility()` is `true` while the banner is on screen: the visitor has not chosen, has not closed it, and no dialog is open. Use it to move your own floating elements out of the way. It is not "has the visitor decided": for that, read `useConsent().hasActed`.

`usePreferencesOpen()` and `useOptOutOpen()` report the two dialogs.

## Language and text

<Framework when="nextjs react">

`useTranslations()` returns the text for the active language, the same strings the components show, and re-renders when the language changes. `useLanguage()` returns the active `language`, its `direction` for right-to-left layouts, the loaded `languages`, and `setLanguage(tag)`. [Translations](/docs/translations) has a picker built on it.

</Framework>

<Framework when="vue nuxt">

`useTranslations()` returns the text for the active language, the same strings the components show, and updates when the language changes. `useLanguage()` returns the active `language`, its `direction` for right-to-left layouts and the loaded `languages` as computed refs, plus `setLanguage(tag)`, which returns a promise. [Translations](/docs/translations) has a picker built on it.

</Framework>

<Framework when="svelte sveltekit">

`useTranslations()` returns the text for the active language, the same strings the components show, and updates when the language changes. `useLanguage()` returns the active `language`, its `direction` for right-to-left layouts and the loaded `languages` as reactive fields, plus `setLanguage(tag)`, which returns a promise. [Translations](/docs/translations) has a picker built on it.

</Framework>

## A custom reload notice

`useReloadNotice()` returns `required`, the tool ids in `reasons`, and `dismiss()`. Most sites should render [`ReloadNotice`](/docs/components/reload-notice) instead; use the hook only for your own markup.

## Common mistakes

**"Ask for consent" shows while the visitor is inside the dialog.**
You used `useBannerVisibility()` for "has not decided yet". Use `useConsent().hasActed`.

**A custom category is missing from your list.**
You wrote the five built-in names by hand. Render from `useCategories().list`.
