---
title: Meta Pixel
description: Load the Meta Pixel only after advertising consent, and pause it when consent is withdrawn.
frameworks: [nextjs, react, vue, nuxt, core]
---

`metaPixel()` loads the Meta Pixel after the visitor grants the advertising category. When consent is withdrawn, it tells Meta to stop with Meta's own consent call and clears the `_fbp` and `_fbc` cookies. When consent is granted again, tracking resumes without loading the script a second time.

## Set it up

<Framework when="nextjs react core">

Install the integrations package and add `metaPixel()` to the `initCookieYes()` call you already have:

</Framework>
<Framework when="vue">

Install the integrations package and add `metaPixel()` to the config you pass to `app.use(CookieYes, config)`:

</Framework>
<Framework when="nuxt">

Install the integrations package and add `metaPixel()` to `cookieyes.integrations` in `app/app.config.ts`:

</Framework>

```npm
npm install @cookieyes/scripts
```

<Framework when="nextjs react">

```tsx title="app/consent-manager.tsx"
"use client";

import { initCookieYes } from "@cookieyes/react";
import { metaPixel } from "@cookieyes/scripts";

initCookieYes({
  mode: "cookie-only",
  regulation: "GDPR",
  integrations: [metaPixel({ pixelId: "123456789012345" })],
});
```

</Framework>
<Framework when="vue">

```ts title="src/consent-manager.ts"
import type { App } from "vue";
import { CookieYes, type CookieYesConfig } from "@cookieyes/vue";
import { metaPixel } from "@cookieyes/scripts";
import "@cookieyes/vue/styles.css";

const config: CookieYesConfig = {
  mode: "cookie-only",
  regulation: "GDPR",
  integrations: [metaPixel({ pixelId: "123456789012345" })],
};

export function setupConsent(app: App): void {
  app.use(CookieYes, config);
}
```

This is the `consent-manager.ts` from [Installation](/docs/getting-started/installation) with the integration added.

</Framework>
<Framework when="nuxt">

```ts title="app/app.config.ts"
import { metaPixel } from "@cookieyes/scripts";

export default defineAppConfig({
  cookieyes: {
    integrations: [metaPixel({ pixelId: "123456789012345" })],
  },
});
```

`integrations` holds functions, so it goes in `app.config.ts`, not `nuxt.config.ts`. The module merges it with the `cookieyes` key in `nuxt.config.ts` from [Installation](/docs/getting-started/installation), where `regulation` and the rest of your configuration stay.

</Framework>
<Framework when="core">

```ts title="src/consent.ts"
import { initCookieYes } from "@cookieyes/core";
import { metaPixel } from "@cookieyes/scripts";

initCookieYes({
  mode: "cookie-only",
  regulation: "GDPR",

```

</Framework>

Remove any pixel snippet you pasted into the page by hand. The integration adds the script and sends the first `PageView` itself.

Track events with `fbq("track", …)` as usual. Before the visitor consents, `fbq` is not on the page yet, so guard the call:

```ts check="false"
window.fbq?.("track", "Purchase", { value: 49, currency: "EUR" });
```

## Options

| Option | Default | What it does |
| --- | --- | --- |
| `pixelId` | required | The numeric id from Meta Events Manager |
| `category` | `"advertisement"` | The category the visitor must grant |
| `autoPageView` | `true` | Send the first `PageView` when the pixel loads. Set `false` if you send page views yourself, for example in a single-page app |
| `limitedDataUse` | automatic | Meta's US privacy flag. Left unset, it turns on for every visitor covered by CCPA. `true` or `false` forces it |
| `id` | `"meta"` | Only needed when you run more than one pixel |

## Common mistakes

**`fbq is not defined` in the console.**
The call ran before consent. Use `window.fbq?.(…)` as shown above.

**Every event arrives twice in Events Manager.**
The pixel is also loaded by a Google Tag Manager container. Load it in one place only: see [Google Tag Manager → Tags inside the container](/docs/integrations/google-tag-manager#tags-inside-the-container).
