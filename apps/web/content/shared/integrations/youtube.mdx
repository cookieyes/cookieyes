`YouTubeEmbed` shows a YouTube video only while the visitor allows its category. Until then it shows a placeholder that looks like a video, with a button that allows the category, and nothing is requested from YouTube or Google. If the visitor withdraws consent, the player is removed again.

A YouTube player contacts Google as soon as it loads, before anyone presses play. On `youtube.com` it also sets cookies at that moment and contacts Google's advertising service. That is why the video waits for consent.

## Set it up

<Framework when="nextjs react">

```tsx title="app/product-tour.tsx"
"use client";

import { YouTubeEmbed } from "@cookieyes/react";

export function ProductTour() {
  return <YouTubeEmbed videoId="VIDEO_ID" title="Product tour" />;
}
```

</Framework>

The video id is the part after `v=` in the video's address, or after `/shorts/` for a Short. For a playlist, pass `playlistId` instead of `videoId`: the part after `list=`.

`title` is required. It names the video for screen readers.

### Change the size

The video fills the width of its container at 16:9. The placeholder and the player share one box, so nothing moves when they swap. To change the size, give the box a class of your own:

```css
.product-tour {
  max-width: 640px;
}

/* A Short is taller than it is wide. */
.short-video {
  max-width: 360px;
  aspect-ratio: 9 / 16;
}
```

<Framework when="nextjs react">

Pass the class as `className`. Load your stylesheet after the SDK's, so that your class wins.

</Framework>

<Framework when="vue nuxt svelte">

Pass the class as `class`. Load your stylesheet after the SDK's, so that your class wins.

</Framework>

### Add a poster

`poster` shows an image behind the placeholder, such as `poster="/images/product-tour.jpg"`. Host the image yourself. YouTube's own thumbnails come from a Google server, so using one would contact Google before consent.

## Options

| Option | Default | What it does |
| --- | --- | --- |
| `videoId` | none | The video or Short to play. Give this or `playlistId`, not both |
| `playlistId` | none | The playlist to play |
| `title` | none | Required. Names the video for screen readers |
| `category` | `"advertisement"` | The category the visitor must grant |
| `params` | none | YouTube player parameters, added to the address as you give them, such as `{ start: 30 }` |
| `domain` | `"youtube-nocookie.com"` | `"youtube.com"` loads the standard player instead of the privacy-enhanced one |
| `poster` | none | The address of an image you host, shown behind the placeholder |

<Framework when="nextjs react">

`className` and `style` go to the box. Every other `<iframe>` attribute is passed to the iframe once it appears. The iframe already has the `allow`, `allowFullScreen` and `referrerPolicy` values of YouTube's own embed code, and `loading="lazy"`.

</Framework>

The placeholder text follows the visitor's language. To change the wording, set `embedPlaceholder.message`, `embedPlaceholder.allow` and `embedPlaceholder.privacyPolicy` in `i18n`; see [Translations](/docs/translations).

## Use your own player

If you already use a player library, keep it and render it only while the category is granted:

<Framework when="nextjs react">

```tsx title="app/own-player.tsx"
"use client";

import { useConsentCategory } from "@cookieyes/react";
import type { ReactNode } from "react";

export function OwnPlayer({ player, placeholder }: { player: ReactNode; placeholder: ReactNode }) {
  const allowed = useConsentCategory("advertisement");
  return allowed ? player : placeholder;
}
```

</Framework>

<Framework when="vue">

```vue title="src/components/OwnPlayer.vue"
<script setup lang="ts">
import { useConsentCategory } from "@cookieyes/vue";

const allowed = useConsentCategory("advertisement");
</script>

<template>
  <slot v-if="allowed" />
  <slot v-else name="placeholder" />
</template>
```

</Framework>

<Framework when="nuxt">

```vue title="app/components/OwnPlayer.vue"
<script setup lang="ts">
const allowed = useConsentCategory("advertisement");
</script>

<template>
  <slot v-if="allowed" />
  <slot v-else name="placeholder" />
</template>
```

</Framework>

<Framework when="svelte">

```svelte title="src/lib/OwnPlayer.svelte"
<script lang="ts">
  import { useConsentCategory } from "@cookieyes/svelte";
  import type { Snippet } from "svelte";

  let { children, placeholder }: { children: Snippet; placeholder: Snippet } = $props();
  const allowed = useConsentCategory("advertisement");
</script>

{#if allowed.current}
  {@render children()}
{:else}
  {@render placeholder()}
{/if}
```

</Framework>

When the visitor withdraws consent, `allowed` turns false and your player is removed. Two things to check in your library:

- **YouTube's player script.** If you add `https://www.youtube.com/iframe_api` yourself, load it with [GatedScript](/docs/components/gated-script), not with a plain script tag.
- **Thumbnails.** Some libraries show the video's thumbnail before a click and fetch it from Google or another outside server. Give them an image you host, or switch the preview off.

## Good to know

- **The category.** YouTube's player can set advertising cookies, so the default is `advertisement`. The category must exist in your `categories` list.
- **`youtube-nocookie.com` still needs consent.** It is YouTube's privacy-enhanced mode: YouTube says views there are not used to personalise the visitor's YouTube experience or ads. The player still contacts Google when it loads and still stores data in the browser.
- **The button allows the whole category.** It grants that one category for the whole site and keeps the visitor's other choices. The choice is saved like one made in the banner.
- **Withdrawal removes the player at once.** What YouTube already stored in the browser stays: it belongs to YouTube's site, and your page cannot delete it.
- **Content-Security-Policy.** Add `https://www.youtube-nocookie.com` to `frame-src`, or `https://www.youtube.com` if you set `domain`. A poster from another origin needs that origin in `img-src`. The placeholder needs nothing more; see [Content Security Policy](/docs/styling/csp).
- **Age-restricted videos** do not play in an embed. The player sends the visitor to YouTube to watch them.
- **Keyboard and screen readers.** The placeholder's button and link work with the keyboard, and the placeholder is named after `title`.

## Check it works

Open your site in a private window and watch the Network tab:

1. Before a decision: the placeholder shows, and there is no request to `youtube-nocookie.com`, `google.com` or `ytimg.com`.
2. Press the button in the placeholder: the player loads from `youtube-nocookie.com`.
3. Withdraw consent in the preferences dialog: the placeholder is back, and no new request goes to those hosts.
4. After a reload: the placeholder again, and still no request.

## Common mistakes

**The placeholder has no styling.**
The SDK stylesheet is missing. It is the same one the banner needs; see [Installation](/docs/getting-started/installation).

**The video never appears, even after accepting.**
The `category` is not in your `categories` list, or your Content-Security-Policy has no `frame-src` entry for YouTube. A development build names an unknown category in the console.

**YouTube is contacted before consent.**
Something else on the page still loads from YouTube: a plain `<iframe>`, or YouTube's own thumbnail used as the `poster`.
