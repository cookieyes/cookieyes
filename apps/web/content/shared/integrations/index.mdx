---
title: Overview
description: Load third-party tools only after consent, with a ready-made integration or your own.
frameworks: [nextjs, react, core]
---

An integration loads a third-party tool only after the visitor grants its category, and stops it again when consent is withdrawn. You add it to `initCookieYes()` once; no consent checks in your own code. Every ready-made integration comes from one extra package:

```npm
npm install @cookieyes/scripts
```

Tool not listed? [Custom integration](/docs/integrations/custom-integration) loads any script after consent in a few lines.
