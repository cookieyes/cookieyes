Google Analytics 4, Google Ads and Google Tag Manager read consent through Google Consent Mode. It has two halves: a default that says "denied" before any Google tag runs, and an update each time the visitor decides. The SDK sends the updates on its own, on page load and on every change. You add the default.

Skip this page if you use no Google product.

## Add the default

<Framework when="nextjs">

Add `<GoogleConsentMode />` to the root layout from [Installation](/docs/getting-started/installation), as the first thing in `<body>`. It prints one inline script, so it runs before anything else on the page. Everything else stays as it is: `<CookieYesRoot />` still renders the banner and dialogs.

```tsx title="app/layout.tsx" check="false"
import { GoogleConsentMode } from "@cookieyes/nextjs/server";
import { CookieYesRoot } from "./consent-manager";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <GoogleConsentMode />
        <CookieYesRoot />
        {children}
      </body>
    </html>
  );
}
```

</Framework>

<Framework when="vue">

Call `bootstrapGoogleConsentMode()` before `app.use(CookieYes, config)`, in the same file. Everything else in that file stays as it is:

```npm

```

```ts title="src/consent-manager.ts"
import type { App } from "vue";

  regulation: "GDPR",

  app.use(CookieYes, config);
```

<Framework when="nuxt">

Turn on the `googleConsentMode` option in `nuxt.config.ts`. The module then writes the default right after `<meta charset>` in every page, ahead of every other tag in `<head>`, as an inline script, so it runs before any Google tag. This includes `ssr: false` pages, pages from `nuxt generate` and cached routes. Everything else stays as it is: `<CookieYesRoot />` still renders the banner and dialogs.

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
  modules: ["@cookieyes/nuxt"],
  cookieyes: {
    regulation: "GDPR",
    googleConsentMode: true,
  },
});
```

`true` uses the defaults. To change them, pass the options `bootstrapGoogleConsentMode()` takes in the other packages instead, for example `{ urlPassthrough: true }`. The option needs no extra package.

</Framework>

<Framework when="sveltekit">

Turn on the `googleConsentMode` option of the handle in `src/hooks.server.ts`. The handle then writes the default right after `<meta charset>` in every page it renders, prerendered pages included, ahead of every other tag in `<head>`, as an inline script, so it runs before any Google tag. ## Which category controls which signal

| Category | Google signals it grants |
| --- | --- |
| `necessary` | none |
| `functional` | `functionality_storage`, `personalization_storage` |
| `analytics` | `analytics_storage` |
| `performance` | none |
| `advertisement` | `ad_storage`, `ad_user_data`, `ad_personalization` |

`security_storage` is always granted. A signal with no category stays denied. If you define your own categories, give each one a `gcm` list of the signals it grants: see [Configuration → Consent categories](/docs/getting-started/configuration#consent-categories).

## Load the tag before or after consent

Every Google integration takes a `consentMode` option:

- **`"advanced"`** (default): the tag loads at once. While consent is denied, Google receives only cookieless pings, as Consent Mode allows. The tag stays loaded when consent is withdrawn.
- **`"basic"`**: the tag loads only after its category is granted, and is removed when consent is withdrawn. Nothing reaches Google before a yes.

```ts check="false"
ga4({ measurementId: "G-XXXXXXX", consentMode: "basic" })
```

On withdrawal, `"basic"` clears that product's own cookies, and removes the shared Google library once no other Google product on the page is still active.

## Common mistakes

**A returning visitor is treated as denied, although they accepted last time.**
The default snippet is missing, so the update sent on page load was skipped. Look for the warning above, then add the default as shown.

**GA4 events are counted twice.**
Both `googleTagManager()` and `ga4()` load the same property. Use one of them for each product. The SDK logs a warning when it sees both.

**With `"basic"`, the tag never loads.**
Its category is not granted yet. That is the point of `"basic"`.
