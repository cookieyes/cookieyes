<Framework when="core">

This page applies to the banner from [`@cookieyes/vanilla`](/docs/getting-started/vanilla). `@cookieyes/core` alone draws nothing, so there is nothing for it to style.

</Framework>

## What it does

<Framework when="nuxt">

The Nuxt module does all of this for you; there is nothing to set up. The rest of the page explains what it does.

</Framework>

<Framework when="sveltekit">

`cookieyesHandle` does all of this for you; there is nothing to set up beyond the stylesheet route from [Installation](/docs/getting-started/installation). The rest of the page explains what it does.

</Framework>

The normal stylesheet import puts the stylesheet on the critical path: the browser waits for it before painting anything. On a slow connection that delay is longer than everything else the SDK does. `critical.css` is the small part of the stylesheet that paints the banner; put it inline in `<head>` and load the full stylesheet without blocking, and the banner is styled on the first frame.

<Framework when="nextjs react vue svelte core">

This is an optimisation. If your first-paint numbers are fine, skip it.

</Framework>

| File | Contents | Size |
| --- | --- | --- |
| `styles.css` | Everything: banner, dialogs, toggles, recall button, reload notice | about 3.8 KB gzipped |
| `critical.css` | Only what the banner needs to paint | about 1.8 KB gzipped |

<Framework when="nextjs react vue svelte core">

Always load `styles.css` too. `critical.css` alone leaves the preferences dialog unstyled.

</Framework>

## Set it up

<Framework when="nextjs">

Two lines. `<CookieYesStyles />` inlines `critical.css` and loads the full stylesheet without blocking; the route serves that stylesheet.

```tsx title="app/layout.tsx"
import { CookieYesStyles } from "@cookieyes/nextjs/server";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <head>
        <CookieYesStyles />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

```ts title="app/cookieyes/styles.css/route.ts"
export { GET } from "@cookieyes/nextjs/styles-route";
```

Then remove `import "@cookieyes/nextjs/styles.css"` from `consent-manager.tsx`; otherwise the stylesheet is back on the critical path.

</Framework>

<Framework when="react">

Copy the contents of `@cookieyes/react/critical.css` into a `<style>` in your HTML `<head>`, and load `styles.css` without blocking, for example with `<link rel="preload" as="style" onload="this.rel='stylesheet'">`. Then remove `import "@cookieyes/react/styles.css"` from `consent-manager.tsx`; otherwise the stylesheet is back on the critical path.

</Framework>

<Framework when="vue">

Copy the contents of `@cookieyes/vue/critical.css` into a `<style>` in your HTML `<head>`, and load `styles.css` without blocking, for example with `<link rel="preload" as="style" onload="this.rel='stylesheet'">`. Then remove `import "@cookieyes/vue/styles.css"` from `consent-manager.ts`; otherwise the stylesheet is back on the critical path.

</Framework>

<Framework when="svelte">

Copy the contents of `@cookieyes/svelte/critical.css` into a `<style>` in your HTML `<head>`, and load `styles.css` without blocking, for example with `<link rel="preload" as="style" onload="this.rel='stylesheet'">`. Then remove `import "@cookieyes/svelte/styles.css"` from `src/main.ts`; otherwise the stylesheet is back on the critical path.

</Framework>

<Framework when="sveltekit">

Nothing to do. On every page the handle writes `critical.css` inline right after `<meta charset>`, ahead of every other tag in `<head>`, and links the full stylesheet so it loads without blocking; the SDK switches it on once it starts. The stylesheet route serves it at `/cookieyes/styles.css`, under your app's base path, compressed and cached for a year under a versioned address:

```ts title="src/routes/cookieyes/styles.css/+server.ts"
export { GET } from "@cookieyes/sveltekit/styles-route";
```

To mount the route at another path, move the file there and set `stylesHref` on the handle:

```ts title="src/hooks.server.ts"
import { cookieyesHandle } from "@cookieyes/sveltekit";
import { config } from "./lib/cookieyes";

export const handle = cookieyesHandle({ ...config, stylesHref: "/assets/cookieyes.css" });
```

The tags are written into the HTML SvelteKit sends, so they are also there on routes with `ssr = false` and on prerendered pages. In a build with no server, such as `adapter-static`, add `export const prerender = true;` to the stylesheet route so it is written as a file.

</Framework>

<Framework when="nuxt">

Nothing to do. On every page the module writes `critical.css` inline right after `<meta charset>`, ahead of every other tag in `<head>`, and links the full stylesheet so it loads without blocking; the SDK switches it on once it starts. A route the module adds serves that stylesheet at `/cookieyes/styles.css`, under your app's base URL (`app.baseURL`, or `NUXT_APP_BASE_URL` at run time), compressed and cached for a year under a versioned address. To serve it from another path, set `stylesHref`:

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
  modules: ["@cookieyes/nuxt"],
  cookieyes: {
    stylesHref: "/assets/cookieyes.css",
  },
});
```

The tags are written into the HTML Nuxt sends, so they are also there with `ssr: false`, on prerendered pages and on routes with `swr`, `isr` or `cache` route rules. `nuxt generate` writes the stylesheet as a static file next to your pages, since there is no server to answer the route.

</Framework>

<Framework when="core">

Copy the contents of `@cookieyes/vanilla/critical.css` into a `<style>` in your HTML `<head>` and keep the `styles.css` import. To have the banner itself in the first frame, not only its styles, put the output of `renderShell(config)` at the start of `<body>`: see [Banner with no framework](/docs/getting-started/vanilla#show-the-banner-before-any-script-runs).

</Framework>

If you send a `Content-Security-Policy`, the inline block needs its hash in `style-src`. See [CSP](/docs/styling/csp).

## Common mistakes

<Framework when="nextjs react vue svelte core">

**The preferences dialog is unstyled, the banner is fine.**
Only `critical.css` is loaded. Load `styles.css` too.

</Framework>

<Framework when="nuxt sveltekit">

**The preferences dialog is unstyled, the banner is fine.**
The full stylesheet did not load. In the Network tab, `/cookieyes/styles.css`, or your `stylesHref`, must return CSS.

</Framework>

<Framework when="nextjs react core">

**Nothing got faster.**
The full stylesheet is still imported in `consent-manager.tsx`. Remove that import.

</Framework>

<Framework when="vue">

**Nothing got faster.**
The full stylesheet is still imported in `consent-manager.ts`. Remove that import.

</Framework>

<Framework when="svelte">

**Nothing got faster.**
The full stylesheet is still imported in `src/main.ts`. Remove that import.

</Framework>
