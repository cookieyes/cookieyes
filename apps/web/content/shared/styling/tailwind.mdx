This page applies to the banner from [`@cookieyes/vanilla`](/docs/getting-started/vanilla). `@cookieyes/core` alone draws nothing, so there is nothing for it to style.

</Framework>

## Set it up

Import the SDK's stylesheet **after** Tailwind. Tailwind's preflight resets buttons and headings; loaded after the SDK, it would strip the banner's own button styles.

<Framework when="nextjs react">

```css title="app/globals.css"
@import "tailwindcss";
@import "@cookieyes/react/styles.css";
```

</Framework>

<Framework when="core">

```css title="src/styles.css"
@import "tailwindcss";
@import "@cookieyes/vanilla/styles.css";
```

</Framework>

If you import the stylesheet in your consent file instead, remove that import and keep this one, so the order is fixed in one place.

<Framework when="nextjs react">

## Three ways to use utilities

**On a component.** `className` is added to the component's own classes:

```tsx check="false"
<CookieBanner className="shadow-2xl ring-1 ring-black/5" />
```

`RecallButton` is the exception: its `className` replaces the default class. Keep `cy-widget` if you want the default look: `<RecallButton className="cy-widget ring-2" />`.

</Framework>

<Framework when="core">

## Use utilities on parts

</Framework>

**On a part, with `@apply`.** Best for anything systematic:

<Framework when="nextjs react">

```css title="app/globals.css"
@import "tailwindcss";
@import "@cookieyes/react/styles.css";

[data-cy-part="banner"] {
  @apply max-w-lg rounded-xl p-6 shadow-2xl;
}

[data-cy-part="accept-all"] {
  @apply font-semibold;
}
```

</Framework>

<Framework when="core">

```css title="src/styles.css"
@import "tailwindcss";
@import "@cookieyes/vanilla/styles.css";

[data-cy-part="banner"] {
  @apply max-w-lg rounded-xl p-6 shadow-2xl;
}

[data-cy-part="accept-all"] {
  @apply font-semibold;
}
```

</Framework>

<Framework when="nextjs react">

**On primitives.** Build the banner from [primitives](/docs/headless/banner) and put utilities straight on your elements.

</Framework>

## Good to know

- A utility has the same strength as the SDK's own rule, so it wins only if your CSS comes after `styles.css`. Do not use the `!` modifier or `@layer components` for these rules; both hide the ordering problem instead of fixing it.
- The components render into `<body>`, so `group-` and `peer-` variants from your tree do not reach them.
- The SDK does not read Tailwind's `dark` class. Set `colorScheme` to match your default scheme and switch the variables from `html.dark`: see [Colour scheme](/docs/styling/color-scheme).
<Framework when="nextjs react">

- Arbitrary values set the SDK's variables: `<CookieBanner className="[--cy-primary:#7c3aed]" />`. This works only while `primaryColor` is not set in `theme`.

</Framework>


## Common mistakes

**The banner's buttons look like plain text.**
Tailwind loaded after the SDK's stylesheet. Put the `@cookieyes` stylesheet import last.

<Framework when="nextjs react">

**A utility on `<CookieBanner>` does nothing.**
Your CSS comes before `styles.css`, or the value is set in `theme`.

**`<RecallButton className="...">` lost its style.**
`className` replaces the default class there. Include `cy-widget`.

</Framework>
