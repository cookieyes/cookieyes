## What it does

Every element the SDK renders carries a `data-cy-part` attribute: `banner`, `accept-all`, `dialog`, `toggle` and so on. Target it in your own stylesheet to change anything `theme` does not cover: width, spacing, shadows, one button, the toggle.

<Framework when="nextjs react core">

```css title="app/consent.css"
[data-cy-part="banner"] {
  max-width: 34rem;
}

[data-cy-part="actions"] {
  gap: 0.75rem;
}

[data-cy-part="accept-all"] {
  font-weight: 600;
}
```

</Framework>

## The toggle

The switch in the preferences dialog is the one element that needs a specific selector. Its colour is painted by a child, `.cy-toggle-track`, and the SDK's own rule for the checked state is stronger than a single part selector, so repeat the attribute once to outrank it:

<Framework when="nextjs react core">

```css title="app/consent.css"
[data-cy-part="toggle"][data-cy-part][data-cy-state="on"] .cy-toggle-track {
  background: #15803d;
}
```

</Framework>

## Good to know

<Framework when="nextjs react core">

**Global CSS only.** The banner, dialogs and recall button render into `<body>`, so a rule scoped to your app, such as `.app-shell [data-cy-part="banner"]`, matches nothing, and CSS Modules or styled-components classes do not reach them.

</Framework>

<Framework when="vue nuxt">

**Global CSS only.** The banner, dialogs and recall button render into `<body>`, so a rule scoped to your app, such as `.app-shell [data-cy-part="banner"]`, matches nothing, and a `<style scoped>` block or CSS Modules in one of your components does not reach them.

</Framework>

<Framework when="svelte">

**Global CSS only.** The banner and recall button render into `<body>`, so a rule scoped to your app, such as `.app-shell [data-cy-part="banner"]`, matches nothing. A `<style>` block in one of your components is scoped to that component's own elements, so it does not reach any CookieYes element. Use a global stylesheet, or wrap the selector in `:global(...)`.

</Framework>

<Framework when="astro">

**Global CSS only.** The banner and recall button render into the element `<CookieYesRoot />` writes, and the dialogs into `<body>`, so a rule scoped to your app, such as `.app-shell [data-cy-part="banner"]`, matches nothing when the root sits outside `.app-shell`. A `<style>` block in one of your components is scoped by Astro to that component's own elements, so it does not reach any CookieYes element. Use a global stylesheet such as `src/styles/consent.css`, or `<style is:global>`.

</Framework>

<Framework when="sveltekit">

**Global CSS only.** The banner and recall button render into `<body>`, so a rule scoped to your app, such as `.app-shell [data-cy-part="banner"]`, matches nothing. A `<style>` block in one of your components is scoped to that component's own elements, so it does not reach any CookieYes element. Use a global stylesheet such as `src/app.css`, or wrap the selector in `:global(...)`.

</Framework>

**Shared names.** `title`, `close`, `accept-all`, `reject-all` and `branding` exist on more than one surface. To style one, add its parent: `[data-cy-part="banner"] [data-cy-part="title"]`.

**Fonts.** The components set their own font and do not inherit yours. Use `theme.fontFamily`, or set `--cy-font` in CSS.

**Variables versus rules.** A rule on a part (`font-weight`, `max-width`) always works. A `--cy-*` variable set in CSS works only while the same value is not set in `theme`; see [Theme tokens](/docs/styling/theme-tokens#good-to-know).

## Common mistakes

<Framework when="nextjs react vue svelte core">

**A rule does nothing.**
Your stylesheet loads before the SDK's. Import it after `styles.css`, or add the parent part to the selector.

</Framework>

<Framework when="nuxt">

**A rule does nothing.**
The file is missing from the `css` option, or the selector is weaker than the SDK's own rule. Add it to `css`, or add the parent part to the selector.

</Framework>

<Framework when="astro">

**A rule does nothing.**
The stylesheet is not imported anywhere, or the selector is weaker than the SDK's own rule. Import it in your layout, or add the parent part to the selector.

</Framework>

<Framework when="sveltekit">

**A rule does nothing.**
The stylesheet is not imported anywhere, or the selector is weaker than the SDK's own rule. Import it in `src/routes/+layout.svelte`, or add the parent part to the selector.

</Framework>

**A scoped selector matches nothing.**
The components are under `<body>`, outside your app's element. Drop the ancestor.

**The checked toggle kept the default colour.**
Use the selector from [The toggle](#the-toggle) above.

**A banner rule also changed the dialog heading.**
`title` is shared. Add `[data-cy-part="banner"]` in front.
