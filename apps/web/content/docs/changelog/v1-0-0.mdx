### Highlights

{/* source: apps/web/content/docs/changelog.mdx (pre-migration, see git history):160 */}
This is the first stable release of `@cookieyes/core`, `@cookieyes/react`, `@cookieyes/nextjs` and `@cookieyes/cli` — the public API adopts semantic versioning from this point on.

{/* source: apps/web/content/docs/changelog.mdx (pre-migration, see git history):161 */}
It ships GDPR and CCPA consent banners, `cookie-only` and self-hosted consent modes, the `GatedScript` and `GatedFrame` controls for gating a script or an iframe on consent, the hooks API, and the headless slot primitives — `Banner`, `Preferences`, `OptOut` — for building fully custom consent UI.
