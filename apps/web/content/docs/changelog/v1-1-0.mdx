### Added

{/* source: apps/web/content/docs/changelog.mdx (pre-migration, see git history):134 */}
`<CookieBanner />` is now present in the server-rendered HTML on every load, instead of appearing only after client hydration completes. This removes the brief empty-page window where a visitor with JavaScript disabled or slow to load would see no banner at all.

{/* source: apps/web/content/docs/changelog.mdx (pre-migration, see git history):135 */}
`[data-cky-banner]`, `.cy-banner` and `.cy-banner-wrap` are now documented, regression-tested public selectors. A consumer can rely on them for custom CSS or end-to-end tests with the same stability guarantee as an exported function — they won't be renamed without a breaking-change notice.

### Changed

{/* source: apps/web/content/docs/changelog.mdx (pre-migration, see git history):141 */}
The full-screen positioning wrapper around the banner is now `display: contents`, so it generates no box of its own. Fixed positioning and `role="dialog"` moved onto the visible `.cy-banner` card itself, which simplifies the DOM a custom stylesheet has to account for.

{/* source: apps/web/content/docs/changelog.mdx (pre-migration, see git history):142 */}
The build moved from tsup to Rollup, emitting minified first-party ESM and CJS bundles plus type declarations. An internal build-tooling change with no expected effect on how the package is consumed.
