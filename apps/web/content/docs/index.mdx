The CookieYes SDK is open source and runs in your frontend. Each framework has its own guide, from installation to every component and hook. Pick the one your app uses:

<Cards>
  <Card
    title="Next.js"
    description="App Router or Pages Router. The banner is rendered on the server, so returning visitors never see it flash."
    href="/docs/nextjs/getting-started/installation"
  />
  <Card
    title="React"
    description="Any React 18+ app: Vite, Create React App, Remix or your own setup."
    href="/docs/react/getting-started/installation"
  />
  <Card
    title="JavaScript (core)"
    description="The framework-free consent engine, for vanilla JavaScript or another framework."
    href="/docs/core/getting-started/installation"
  />
</Cards>

Not sure where to start? Run `npx @cookieyes/cli init` in your project: it detects Next.js or React and writes the setup for you.
