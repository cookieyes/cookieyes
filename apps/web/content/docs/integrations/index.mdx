Every integration here is a preset from `@cookieyes/scripts` — a script that stays out of the DOM
until its category is granted, and that tears itself down (or silences itself) the same way on
revoke. Start with Google Consent Mode v2 if you run any Google product; it underlies three of the
vendor pages below. Otherwise, pick your vendor.
