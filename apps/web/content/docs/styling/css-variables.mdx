### Machine-readable format (design tools, AI coding assistants)

The table above is also published as a [W3C Design Tokens Community Group](https://design-tokens.github.io/community-group/format/) JSON file, generated from the exact same in-memory data — there is no second parse of `cookieyes.css` and no second sidecar, so the two cannot drift from each other:

**[`https://developer.cookieyes.com/design-tokens/cookieyes.tokens.json`](/design-tokens/cookieyes.tokens.json)**

Point a design tool or a coding assistant at that URL to generate CSS, Figma variables, or a theme object without inventing token names. Two tokens are represented honestly rather than as plain literals: `--cy-focus` is a genuine, untransformed reference (`"$value": "{cy.primary}"`), and `--cy-primary-hover` is a reference *plus* a documented deviation — its `$description` states plainly that the real value is a runtime `color-mix()` transform of `--cy-primary`, with the formula machine-readable under `$extensions.cookieyes.transform`. `--cy-on-primary` and `--cy-on-widget-bg` are marked `computed: true` for the same reason: they're JS-derived at runtime, not static colours, and the shipped default is only accurate for the SDK's own default primary/widget-background colour.

## Common mistakes

**Assuming every visible colour is variable-controlled.**
Seventeen aren't — see [Things no variable controls](#things-no-variable-controls) above before concluding a colour is unsupported.

**Looking for a `--cy-*` token that isn't `--cy-`-prefixed.**
There isn't one. Every token this SDK reads carries the prefix, with zero exceptions — the table in [Basic usage](#basic-usage) is the complete list.

**Treating the default shown here as what's currently rendered.**
The values on this page are the SDK's shipped defaults. Your own `theme` config, if you've set one, already overrides some of them — this page doesn't know what you configured, only what ships without it.

## Across the SDK

The tokens live in `@cookieyes/react` and are used identically by `@cookieyes/nextjs`. The `ThemeConfig` type — the `theme` keys nine of these twelve tokens read from — is defined in `@cookieyes/core` and re-exported, though `core` ships no CSS to apply it to.
